# 用量查询配置


CC Switch 可以直接显示 小K的AI站点 的已用额度和剩余额度。用量查询需要使用 小K的AI站点 的

**系统访问令牌和用户 ID**

，不是配置供应商时使用的 API Key。

1. 在 小K的AI站点 供应商卡片右侧点击 **配置用量查询**。


1. 开启 **启用用量查询**，预设模板选择 `NewAPI`。


1. 请求地址填写 `https://api.kkkk24juastin.asia`。前往 小K的AI站点 **个人设置 → 安全设置**生成系统访问令牌；用户 ID 可在个人设置页顶部查看。


1. 将系统访问令牌和用户 ID 填入对应字段。


1. 点击 **保存配置**。返回供应商列表后，即可在 小K的AI站点 卡片上查看用量并手动刷新。
