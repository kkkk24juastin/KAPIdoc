## 当前可见分组

以下分组和倍率根据当前定价页整理。倍率会影响实际扣费，模型可用性和具体模型列表请以控制台定价页的实时内容为准。

| `grok` | `x0.2` | Grok 相关模型 |

### 倍率说明

- `x1` 表示按基础价格计费。
- 小于 `x1` 表示折扣，例如 `x0.25` 表示按基础价格的 25% 计费。
- 大于 `x1` 表示加价，例如 `x1.2` 表示按基础价格的 120% 计费。
- 以上倍率是截图中当前可见的值，后续可能随服务调整。

## 如何选择分组

1. 先在定价页筛选目标分组，确认该分组实际展示的模型和请求协议。
2. 创建 API 令牌时，分组名称必须与定价页显示的名称完全一致。
3. 配置客户端时，模型 ID 也必须从当前分组的模型列表中复制，不要沿用其他分组的模型名。
4. 如果某个教程中的旧分组名称与定价页不一致，以定价页和本页的最新分组为准。

## 查看实时模型

1. 打开[定价页](https://api.943827561.xyz/pricing)。
2. 使用分组筛选器选择目标分组。
3. 查看该分组下当前可用的模型、协议和价格。

也可以参考[创建 API 令牌](../register/4-token.md)了解令牌创建流程。
